# Assets and attribution

The globe/island presentation, procedural landmark geometry and cloud artwork are project assets. Islands illustrate visit order; they are not geographic terrain or verified directions.

`packages/scene/src/land-data.ts` records the Natural Earth 1:110m land source and public-domain status. The simplified geography is visual context, not navigation data. The additional `land-110m.json` geographic asset retains its original data structure.

Icons use `lucide-react` under its upstream ISC license. Next's font integration loads and self-hosts the configured Geist/Instrument Serif fonts; their upstream font licenses apply. Other dependencies retain their published licenses.

Leaflet maps display OpenStreetMap attribution. Optional Google imagery, SDK controls and attribution remain Google's surface and terms. Runtime Qloo photos/facts retain source provenance; provider responses, map tiles, personal media and competitor assets are not included as repository captures.

The MIT LICENSE covers project-owned contributions and does not replace third-party data, dependency or service terms.
